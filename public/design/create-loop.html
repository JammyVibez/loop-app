Behaviour & rules

Default state
  • Empty, Text selected. The composer opens with a serif prompt and a live caret — no box, no border.
  • One primary action. Only the Create Loop button carries the saturated aurora gradient.
  • Glass, not grey. Panels are 4% white + 9% hairline + 18–28px blur; artwork drifts under them.
  • 44px minimum. Header controls, tools and chips all meet a 44px touch target.
  • 1.8px icons. Every line icon shares the same stroke, rounded caps and no fills.
  • Live draft. Typing updates 0/1,800 and the ring, then “Saving…” becomes “Draft saved” after 700ms.
